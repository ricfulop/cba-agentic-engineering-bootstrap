# Verify before claiming

A value in a document is not evidence that a calculation was run. Before
quoting or building on a performance number, a status phrase, or a count:

1. Find the generating code or the primary record.
2. Run it, or read the record, today.
3. State the filter the measurement applied.
4. If the record is silent, say it is silent and open the item. Do not
   derive a requirement to fill the gap.

Withdraw, do not delete. When a claim falls, banner the document and
split what is withdrawn, what is contaminated, and what still stands. A
withdrawn claim is not thereby reversed.

Do not upgrade `candidate`, `exploratory`, `non-confirmatory`,
`PLACEHOLDER`, or `QUOTE REQUIRED` without the corresponding analysis
changing.

A correctly computed number can still not measure what its name says.
Resolve the label against the code that produced it before it reaches a
paper, abstract, or deck.

Never invent DOIs. Prefer scite; otherwise `paper-lookup` plus Crossref.
