# Literature corpus

Load `domain-corpus-bootstrap`. The corpus comes before the analysis.

If a FLARE checkout is present, `FLARE/literature/` is the reference
implementation (stdlib scripts under `literature/scripts/`). Read
`literature/README.md` there before writing new tooling. Otherwise follow
the generic steps in `domain-corpus-bootstrap`.

Do not reason about a new domain from model weights alone.
