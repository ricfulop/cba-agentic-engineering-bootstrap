# CBA Agentic Engineering Bootstrap Toolkit — project instructions

If you open this CBA bootstrap toolkit clone as a worktree, the same
research defaults apply. The skill tree is `skills/`. Figure styles are
`lib/styles.py`.

See `zed/AGENTS.md` for the personal-instruction copy that `install.sh --zed`
appends to `~/.config/zed/AGENTS.md`, and `rules/cba-research.mdc` for Cursor.

- Figures: `lib/styles.py`. Never bare `plt.figure()`.
- Prose: `manuscript-prose-style`. American English, noun-phrase headings.
- Citations: scite if available; never invent DOIs.
- Affiliation: Center for Bits and Atoms, Massachusetts Institute of Technology.
